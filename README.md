# Restamp Website — Next.js + Tailwind CSS

A responsive homepage reconstruction based on the supplied Restamp screenshot.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- This is a new Next.js App Router project, not an automatic conversion of the original Lovable source.
- Homepage sections, property cards, navigation and search UI are included.
- Other routes are scaffolded and need their original page content.
- Images are temporary placeholders; replace with licensed Restamp assets.
- Search routes to the relevant page with query parameters; backend search is not connected.
